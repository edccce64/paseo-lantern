## 4. 三张参考图的设计语言分析

### 图 1 · THE GUND
- 视觉：纯黑白 + 荧光色（品红、黄、薰衣草）。1px 纯黑硬边框，零圆角。
- 排版：全大写无衬线 logo 带宽字距；条目标题用衬线体；辅助信息用小号等宽字。
- 结构：顶部 logo + 搜索 + 更多菜单；横向标签分栏；单列列表，图右文左，条目间一条硬横线。
- 识别点：黑框网格 + 荧光小色块（编号 / 标签）。
- 动效：静态截图，无法从图判断。参考同类的档案型站点，通行动效是边框加粗与色块位移，150ms。

### 图 2 · Pinterest（Today / For You / For Later）
- 视觉：白底圆角卡片（12–16px），单一红色强调（#E60023），内容优先。
- 排版：超大衬线标题做主视觉（Breaking News），正文无衬线，标题与正文层级差 2 倍以上。
- 结构：横滑「Top Stories」卡片 + 竖列「Read Later」流；底部 4 项 tab；侧栏抽屉放「All Following / Discover / History」。
- 识别点：卡片 = 缩略图 + 来源标识 + 标题 + 日期 + 书签。
- 动效：静态截图，无法从图判断。同类产品通行动效是卡片按下缩放到 0.97 并降透明度，200ms ease-out；横滑卡片吸附；tab 切换 150ms 淡入。

### 图 3 · The Gazette（sleek.design 概念稿）
- 视觉：羊皮纸底（#F4EFE4）+ 墨黑 + 橙色点缀（#B4501E）。全大写小型大写标签 + 极粗衬线大标题 + 首字下沉。
- 结构：报头（卷号 + 报名 + 日期）→ 横排栏目（FRONT PAGE / WORLD / OPINION）→ 卡片网格（档案 tabs：ALL DISPATCHES / IN-DEPTH / OPINIONS / THE ARTS）→ 底部 4 tab。
- 识别点：首字下沉、橙色书签角标、卡片网格里的「ADD CLIPPING」占位卡。
- 动效：这是设计概念稿，没有真实动效数据。

### 共同的行业规律（三张图一致）
1. 一个强调色，只用在一处（选中态、标签、书签），不做多色混用。
2. 字号层级跨度大，主标题与辅助文字差 2 倍以上，不做「全站 13–17px」的均质感。
3. 导航是「标签行」或「底部 tab」二选一，不同时用两套。
4. 圆角要么全开要么全无，不混用。

## 5. 三版模板

三版都已出图，HTML 原稿在 `~/.paseo/daily/mock/`。

| 版 | 名称 | 来源参考 | 主色 | 圆角 | 适合 |
| --- | --- | --- | --- | --- | --- |
| A | 档案室 | THE GUND | 黑白 + 荧光黄 | 0 | 高频扫读，编辑感，硬朗 |
| B | 日报 | The Gazette | 纸色 + 墨黑 + 橙 | 0–2 | 沉浸长读，杂志感 |
| C | 速读 | Pinterest | 白底 + 红 | 16 | 移动端扫读，卡片流 |

每版的落地约束相同：
- 颜色必须走宿主主题（`theme.colors`），纸色方案在深色模式要反相。
- 字体只能��宿主提供的字族，不能自带字体文件。
- 动效用 React Native `Animated` 与 `LayoutAnimation` 实现，时长参数在下方给出。

### A 版动效建议（#未验证，取自行业通行参数）
- 频道切换：列表整体淡出淡入 120ms，不做横向滑动。
- 列表条目按下：背景色 80ms 变浅，不做缩放。
- 刷新：图标 360ms 匀速旋转一圈。
- 未读圆点：首次出现时 200ms 放大到 1。

### B 版动效建议（#未验证）
- 频道切换：像翻报纸，整列 24px 上移 + 淡入，220ms，cubic-bezier(0.2, 0.8, 0.2, 1)。
- 首条头条：入场时从 12px 上移 + 淡入，260ms，其余条目 stagger 60ms。
- 版本切换：正文内容交叉淡入 150ms。
- 收藏：书签角标按下时 120ms 缩放到 0.8 再回弹。

### C 版动效建议（#未验证）
- 卡片按下：缩放 0.97 + 透明度 0.9，200ms ease-out，松手 150ms 回弹。
- 底部 tab 切换：选中圆点 180ms 位移 + 文字颜色渐变。
- 横向卡片流：scroll snap 对齐卡片边缘。
- 正文打开：卡片从点击位置放大展开，260ms。
